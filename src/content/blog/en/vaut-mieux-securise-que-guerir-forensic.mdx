## Description

During a shot put competition, an athlete leaves his computer on with his session unlocked. Someone used the computer and apparently hid a few things. We are given the computer's RAM dump after the incident.
Investigate this memory dump to understand what happened.

The second part of the flag is the name of a specific task.
The two parts are separated by a hyphen "-". For example, if the flag for the first part is "flag1" and the flag for the second part is "flag2", the actual challenge flag will be `404CTF{flag1-flag2}`.

### Recovering a deleted file

After searching a bit, we find the task name, aka Flag2:
`Register-ScheduledTask -Action $Action -Trigger $Trigger -TaskName "XXX"
`
Then I read through the code until I identified base64 in a field and decoded it:
```
klm@KLM:~/CTFs/40424$ echo "e1ByQG5rM2Qt" | base64 -d
{XXXXXX
```

So we now have the full flag: `404CTF{XXXXXXXXX}`
